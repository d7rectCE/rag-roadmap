# RAG / NLP roadmap

Путь от нуля до работающего сервиса с RAG и агентами. Репозиторий — журнал этого
пути: на каждый модуль свой проект, от простого к сложному.

Проекты здесь — это то, что я точно разобрал и могу объяснить построчно, они написаны не мной, а как дополнение к обучающему материалу для изучения uv + git

## О модулях

**Модуль 0 — инженерная база.** Асинхронный Python, HTTP-клиенты с ретраями и
rate limiting, типизация и валидация через pydantic, воспроизводимое окружение.
Всё то, обо что спотыкаешься, когда начинается содержательная часть.

**Модуль 1 — PyTorch и трансформер изнутри.** Тензоры и autograd в объёме, нужном
для чтения кода. Токенизация, эмбеддинги, self-attention, позиционное кодирование,
KV-кэш. Цель — один раз собрать трансформер руками, чтобы дальше уверенно читать
чужой код.

**Модуль 2 — LLM как инструмент.** Промптинг, контекстное окно как ресурс,
structured outputs, tool calling, локальный инференс. Самая недооценённая часть:
большинство продуктовых задач решается здесь, без единого шага обучения.

**Модуль 3 — Retrieval и RAG.** Модели эмбеддингов, векторные БД, парсинг
источников, чанкинг, гибридный поиск, реранкинг, работа с запросом. Основная часть
качества RAG живёт в поиске, а не в генерации.

**Модуль 4 — оценка и наблюдаемость.** Метрики retrieval и генерации, LLM-as-a-judge,
трейсинг, регрессионное тестирование промптов. То, что отличает работающий продукт
от демки.

**Модуль 5 — агенты.** ReAct-цикл, проектирование инструментов, MCP, память,
планирование, agentic RAG, безопасность и prompt injection. И честный разговор о
том, когда агент не нужен.

**Модуль 6 — продакшен.** FastAPI со стримингом, очереди, Docker, серверы инференса,
квантизация, кэширование, эксплуатация.

## Стек

**Используется сейчас**

`Python 3.12` · `asyncio` · `httpx` · `pydantic` · `pydantic-settings` ·
`structlog` · `pytest` · `uv`

**По ходу роадмапа**

| Слой | Инструменты |
|---|---|
| Модели и обучение | PyTorch, Hugging Face `transformers`, `tokenizers`, LoRA / QLoRA |
| Работа с LLM | OpenAI / Anthropic API, structured outputs, tool calling, Ollama, llama.cpp, GGUF |
| Эмбеддинги и поиск | `sentence-transformers`, FAISS, Qdrant, Chroma, pgvector, BM25, кросс-энкодеры |
| Парсинг источников | PyMuPDF, `unstructured`, OCR, layout-модели |
| Оценка и трейсинг | `ragas`, Langfuse, OpenTelemetry |
| Агенты | LangGraph, Pydantic AI, LlamaIndex, MCP |
| Сервис и инференс | FastAPI, Docker Compose, очереди задач, vLLM, TGI, SGLang, GPTQ / AWQ |
## Как это читать

В каждой папке свой README: что за проект, как запустить, что из него вынесено.
Смотреть лучше не отдельный модуль, а несколько подряд — разница между нулевым и
третьим и есть содержание репозитория.
